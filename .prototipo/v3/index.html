O Techdle é um jogo diário sobre hardware. Digite para filtrar o catálogo e compare suas tentativas por colunas (Tipo, Conexão, Função, Energia, etc.). Você pode reaproveitar os componentes UI e JS desta página em qualquer outra seção do site.

Como funciona

1) Procure pelo item

Use o campo de busca: digite e a lista reduz. Se preferir, navegue pelas opções com ↑ ↓ e confirme com Enter.

Reaproveitável: componente Combo (input + listbox) do nosso design system.

2) Compare as colunas

A tabela mostra acertos exatos, parciais (quando há sobreposição) e erros por coluna.

Reaproveitável: componente Tabela de tentativas.

3) Sem limite de tentativas

Por padrão, não há limite. Quer limitar? Ajuste CONFIG.maxAttempts no módulo de estado.

Config pelo módulo state.js.

Sobre os componentes

Design System (CSS)

tokens.css, base.css e os componentes (components.*.css) permitem montar novas páginas consistentes rapidamente.

Módulos (JS)

Utilitários puros (utils/), UI declarativa (ui/), regras de negócio (logic/), carregamento de dados (data.js) e orquestração (controllers.gameController.js).

Dataset

Os itens são lidos de src/componentes.json. Outras páginas podem consumir os mesmos dados sem o jogo.

Feito com ♥ — Techdle modular. Reaproveite os componentes, crie novas páginas e divirta-se.
